# Release checklist

## Local application

- [x] Three main experiences and a complete guided route implemented.
- [x] Credibility challenges use repository-backed facts.
- [x] Deterministic scenario and genuine evidence links implemented.
- [x] Two creatives, three writing situations, and pending/completed result states implemented.
- [x] Strict aggregate and media schemas; no private workbook in source.
- [x] Optional recordings, transcript/caption requirements, and safe fallbacks.
- [x] Keyboard-accessible native dialog, reduced motion, responsive layouts.
- [x] Final verification run recorded in `VERIFICATION.md`.

## Authentic evidence

- [ ] Real adult pilot conducted; achieved sample size reported.
- [ ] Unique invitees separated from invitation deliveries.
- [ ] Usability/reuse denominators reconciled with Yes/No/Not asked.
- [ ] Actual recruitment limitations, missing groups, friction, and lessons recorded.
- [ ] Actual Flow demonstration attached with captions/transcript.
- [ ] Genuine Flow-to-Emergent recordings attached with actual changes and dates.
- [ ] Identifiable footage separately permitted; participant text excluded.

## Emergent deployment and submission

- [ ] Reviewed source uploaded to GitHub and imported into a new Emergent project.
- [ ] Real import incompatibilities resolved and differences documented.
- [ ] Substantive construction, revision, and verification performed inside the new Emergent project through actual Wispr Flow dictation.
- [ ] Public Emergent URL opens without sign-in.
- [ ] Hosted keyboard, mobile, drawer, media, results, and external-link checks pass.
- [ ] Opening, campaign, log, and footer match the actual evidence state.
- [ ] Short experiment report uses actual counts and limitations.
- [ ] Video is at most three minutes and uses genuine recordings.
- [ ] Grant answer uses defensible current quotations; no award/purchase claimed.
- [ ] Final submission reviewed and actually submitted through the challenge process.

Unchecked real-world requirements remain open even when all local automated checks pass.
